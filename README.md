# Real-Time Bot Behavior Anomaly Detection

A research project implementing real-time anomaly detection to identify 
bot behavior patterns in an online game environment. Developed as a 
university security course project.

## Overview

Bots in online games exhibit predictable, non-human movement patterns. 
This project applies behavioral analysis to detect these anomalies in 
real time — concepts directly transferable to network intrusion detection 
and SOC anomaly analysis.

## Implementation

- **Engine:** Unreal Engine 5
- **Language:** C++
- **Method:** Real-time movement pattern analysis and threshold-based 
anomaly flagging

## Key Concepts

- Behavioral baseline establishment
- Anomaly detection via pattern deviation
- Real-time analysis pipeline

## Research Paper

Findings documented in a LaTeX-formatted research paper covering 
methodology, implementation, and results.
